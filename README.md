# Dip Screener — หาหุ้นน่าช้อน (US + SET)

เว็บแอปสแกนหาหุ้นที่ราคาอยู่ในโซน "น่าช้อน" โดยรวมหลายเงื่อนไขเป็นคะแนนเดียว:

- % ที่ราคาต่ำกว่าจุดสูงสุด 52 สัปดาห์
- RSI(14) — วัดภาวะ oversold
- % ราคาต่ำกว่าเส้นค่าเฉลี่ย 50 วัน และ 200 วัน

ปรับน้ำหนักแต่ละเงื่อนไข และรายชื่อหุ้นได้เองในแถบด้านซ้ายของแอป

## ติดตั้งและรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

จากนั้นเปิดเบราว์เซอร์ที่ลิงก์ที่ streamlit แสดง (ปกติ http://localhost:8501)

## เกี่ยวกับแหล่งข้อมูล

แอปนี้ดึงราคาจาก **Yahoo Finance** ผ่านไลบรารี `yfinance` (ฟรี ไม่ต้องขอ API key)
แทนที่จะใช้ Webull เพราะ Webull ไม่มี public API อย่างเป็นทางการสำหรับนักพัฒนาภายนอก —
ไลบรารีที่ไม่เป็นทางการที่มีอยู่ต้องผูกกับบัญชีจริงและมีความเสี่ยงด้านความปลอดภัย/เงื่อนไขการใช้งาน
ข้อมูลจาก Yahoo Finance หน่วงเล็กน้อย (ไม่ใช่ tick แบบ real-time เป๊ะ) แต่เพียงพอสำหรับการสแกนหาโอกาสรายวัน

หุ้นไทยใช้ suffix `.BK` เช่น `PTT.BK`, `CPALL.BK`

## หมายเหตุ

- คะแนน "น่าช้อน" เป็นเครื่องมือกรองตามเทคนิคเท่านั้น ไม่ใช่คำแนะนำการลงทุน
- รายชื่อหุ้น SET เริ่มต้นเป็นชุดหุ้นใหญ่คุ้นเคย ควรตรวจสอบ/ปรับปรุงให้ตรงกับ SET50 ปัจจุบันเอง
